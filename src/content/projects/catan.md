## Overview

A web version of Settlers of Catan for playing online with friends. It reuses
the BlockGameOnline room layer — lobby, accounts, friends, presence, and
invites — and runs on Cloud Run the same way.

- Bots, 1v1 and four-player modes on the standard board.
- Configurable rule options.
