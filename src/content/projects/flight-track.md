## Overview

A personal flight tracking system built on free community ADS-B aggregators
(adsb.fi, adsb.lol, airplanes.live) instead of a paid API.

- A live map, in 2D with a 3D toggle.
- A watchlist that alerts when a tracked aircraft takes off.
- Type and category alerts inside a radius, with a closest-approach prediction.
- Camera pointing on a handheld Raspberry Pi with a Sharp Memory LCD.
