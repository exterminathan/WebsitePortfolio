DRAFT — the one-offs, too small for a section each. Every one of them
exists because some manual step in the editor was being repeated dozens of times
a day.

### Object Validator

DRAFT — Duck Around. What it scans, which broken states it catches
(missing references, unassigned layers, prefab drift?), and how it reports them.

### Child Alphabetical Sorter

DRAFT — Quartermaster. Sorts a transform's children by name so a hierarchy
built by four people stays readable and diffable.

### Replace With Object

DRAFT — Quartermaster. Swaps a selection for a prefab in place, keeping
transform, parent, and sibling order — the alternative was deleting and
re-placing by hand.

### Create Sequential Objects

DRAFT — Quartermaster. Spawns a numbered run of objects along a spacing
rule, for the repeated placements a level needs dozens of.
