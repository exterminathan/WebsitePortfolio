# innate logo concepts

All 41 concepts from the 2026-10-30 logo rounds, kept for later. The full specimen sheet, showing each on light and dark and at favicon sizes, is `docs/innate-logos.html`, published at https://claude.ai/artifact/9pVLyTAyoLaFFP5no4Ksmv.

Every SVG here is 64×64 and uses the ink `#1e1618`, with red `#fc314f` as the accent. In dark contexts, swap the ink for `#ece8e9`. Strokes and fills use `currentColor`, so setting `color` recolors them.
